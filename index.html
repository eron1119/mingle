인증 정보

중요: 현재 화면의 인증 상태와 프로필은 데모용 예시입니다. 실제 신원 확인이 이루어진 것이 아니며, 실제 서비스에서는 인증 제공자와 서버 검증을 연결해야 합니다.

사용자 신고

신고할 사용자를 선택했어요.

데모에서는 신고 내용이 이 브라우저에만 저장되며 운영팀에 전달되지 않습니다. 실제 서비스에서는 서버 저장과 운영자 검토 절차가 필요합니다.

안전 센터

차단한 사용자는 친구 검색 결과에서 숨겨지고, 이 데모에서 해당 사용자와의 채팅도 제한됩니다.

차단·신고 내역은 현재 브라우저에만 저장됩니다. 다른 기기와 공유되거나 운영팀에 자동 전달되지 않습니다.
